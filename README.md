## The entry

`main.py` writes one roast line to `/output/entry.txt`:

> My robot vacuum mapped my whole flat, memorised where the dog sleeps, and still eats the same charging cable every single day.

One line, 126 characters. It roasts a real smart-home gadget behaviour —
a robot vacuum that maps the house in detail yet still eats the same
charging cable every day — instead of the stock fridge-orders-milk joke.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
